# Histórias de Usuário

> Versão versionada no repositório. As histórias são copiadas daqui pelo ID para o prompt da LLM (ver Fluxo de Especificação).
> **Status: RASCUNHO da Fase 1.** Só há o papel do jardineiro. Radar, motor de rega, quarentena, registro diário e filtros ficam para a Fase 2 e ainda não têm histórias.

## Caderno

### US01 — Criar caderno
Como jardineiro, quero criar um caderno para organizar o acompanhamento das minhas plantas.

### US02 — Informar dados do caderno
Como jardineiro, quero definir nome e descrição do caderno para identificá-lo.

## Espécimes

### US03 — Cadastrar espécime
Como jardineiro, quero cadastrar uma planta com espécie, variedade e número para identificá-la unicamente.

### US04 — Arquivar espécime
Como jardineiro, quero marcar uma planta como perdida ou descartada para manter seu histórico sem apagá-lo.

## Fotos

### US05 — Adicionar foto
Como jardineiro, quero adicionar uma foto datada a uma planta para registrar sua evolução.

### US06 — Remover foto
Como jardineiro, quero remover uma foto para corrigir um registro errado.

### US07 — Ver cadeia de fotos
Como jardineiro, quero ver as fotos de uma planta em ordem cronológica para acompanhar sua evolução.

## Configuração do caderno

### US08 — Configurar locais de cultivo
Como jardineiro, quero definir os locais de cultivo do caderno, com recebimento de chuva e exposição ao sol, para associar cada planta a um local.

### US09 — Configurar opções
Como jardineiro, quero definir as listas de estágios e de estados de saúde para padronizar os registros.

### US10 — Configurar campos de registro
Como jardineiro, quero criar campos extras para o diário de uma planta para anotar o que me interessa.

## Pacote do caderno

### US11 — Exportar pacote
Como jardineiro, quero exportar meu caderno completo, com dados e fotos, para fazer backup ou levá-lo a outra máquina.

### US12 — Abrir pacote
Como jardineiro, quero abrir um pacote exportado para restaurar um caderno.
